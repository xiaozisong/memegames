Keyboard Test

目标：观察键盘弹出时，页面是被压缩、抬升，还是自动滚动到输入框。

状态: 等待输入框聚焦
viewport: loading...

顶部输入区

在页面顶部先点一次输入框。

中部输入区

向下滚动后，在中部输入框测试。

长内容区 A

这是一段占位文本，用于拉长页面高度并观察滚动行为。

1. 键盘弹出后，看看当前可视高度是否变小。

2. 看看页面是否自动滚动到焦点输入框。

3. 关闭键盘后，观察滚动位置是否恢复。

长内容区 B

继续拉长页面，保证底部输入框离初始视口较远。

如果你看到内容整体上移，通常是窗口 resize 或 safe area 变化导致。

如果只发生局部滚动，通常是浏览器自动滚动到焦点元素。

长内容区 C

再补一段内容，让页面更接近真实业务长页。

可以多次切换不同输入框，比较键盘行为是否一致。

底部输入区

重点观察：底部输入框聚焦时，页面是否被挤压或抬升。
