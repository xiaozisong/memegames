# cut-rope-nobuild 策划案

## 1. 项目概述

`cut-rope-nobuild` 是一套基于 `Pixi.js + 原生 ESM + CDN` 的无构建割绳子风格小游戏模板，当前真实运行内容已经包含：

- 多关卡切绳玩法
- 点击与滑动切断绳索
- 轻量绳索约束与自由落体物理
- 糖果摆动、旋转与切断后惯性保持
- 星星收集与分数累计
- 目标接收口命中判定
- 通关进入下一关、失败重试
- 背景 / 糖果 / 星星 / 怪物资源链接配置
- 背景音乐配置与首次交互解锁播放
- 切割拖尾特效、绳子弹性曲线与切断回弹
- DOM 卡片式 HUD 与 Modal

本项目不是“只有骨架的空模板”。  
给模型使用时，必须把它当成**已经具备完整单局循环的 Cut the Rope no-build 模板**，不要再按“占位实现”描述。

关键词：

- no-build
- 配置驱动
- 轻物理
- 切绳解谜
- 资源可替换
- 休闲手游反馈

## 2. 模型使用强约束

## 3. 产品定位

### 3.1 目标用户

- 喜欢 Cut the Rope 类轻解谜的休闲用户
- 偏好短局、即时反馈、低学习成本的移动端用户
- 对图片资源、切割特效、反馈动画、简单物理感兴趣的用户

### 3.2 产品目标

- 在 3 秒内让用户理解“切断绳子，让糖果进目标”
- 用星星收集与多绳顺序决策形成解谜动机
- 用贴图资源、背景音乐、切割拖尾和弹性绳索建立成品感

## 4. 当前核心循环

当前真实单局循环如下：

1. 首次进入游戏，显示开始弹窗。
2. 用户点击开始，进入关卡。
3. 糖果在绳索约束下轻微摆动。
4. 用户点击绳子或滑动横切，触发切绳。
5. kernel 更新绳索状态，糖果在重力和惯性作用下运动。
6. 糖果飞行途中可收集星星，累计星星数与分数。
7. 若糖果进入目标接收口，则判定胜利。
8. 若糖果掉出场景，则判定失败。
9. 胜利后点击按钮进入下一关；最后一关完成后回到第一关。失败后点击按钮重试当前关。

## 5. 玩法规则

### 5.1 世界与关卡

- 当前世界尺寸来自 `gameplay_world_width` 与 `gameplay_world_height`
- 当前关卡数量来自 `gameplay_level_count`，并且也会从平铺关卡 key 自动推断
- 当前关卡数据直接写在 `src/config.json`

### 5.2 绳索规则

- 每关至少有 1 条绳索
- 绳索由锚点和长度组成
- 当前支持点击切断
- 当前支持滑动横切
- 当前支持 hover 高亮
- 绳索切断后不可恢复

### 5.3 糖果物理

- 悬挂时：受绳索约束、重力切向分量、摆动力、阻尼影响
- 切断后：自由落体并保持已有速度惯性
- 当前不会因为滑动方向给额外切割冲量
- 当前糖果会根据关卡绳索锚点做出生点稳定化，避免初始位置过于贴边

### 5.4 星星规则

- 当前星星是关卡中的可选收集物
- 糖果触碰星星后立即收集
- 星星收集后增加分数
- 星星总数来自当前关卡配置

### 5.5 目标规则

当前目标接收口支持 2 种形状：

- `circle`
- `rect`

糖果进入目标区域后立即通关。

### 5.6 失败规则

当前失败条件：

- 糖果掉出世界边界 + `gameplay_fail_margin`

### 5.7 关卡推进

- 初始关卡来自 `gameplay_level_index`
- 通关后进入下一关
- 最后一关通关后回到第一关
- 失败后重试当前关
- 首次进入显示开始弹窗；通关进入下一关时默认直接开局

## 6. 分数与反馈

### 6.1 分数

当前分数规则：

- 每收集 1 颗星星：`+100`

当前没有读到更多复杂分数乘区，不要擅自扩写。

### 6.2 动画反馈

当前已实现：

- 切割拖尾
- 切到绳子的命中高亮反馈
- 绳索弹性曲线
- 切断后绳头回弹
- 糖果旋转
- 弹窗出现动画
- 按钮按压反馈

不要把这些写成“未来计划”。

## 7. 视觉与媒体规则

### 7.1 背景

当前支持：

- 默认程序绘制纯色背景
- `presentation_background_asset_url`
- `gameplay_level_<n>_background_asset_url`

优先级：

1. 关卡级背景资源
2. 全局背景资源
3. 默认程序绘制背景

### 7.2 糖果 / 星星 / 怪物资源

当前支持：

- `presentation_candy_asset_url`
- `presentation_star_asset_url`
- `presentation_target_asset_url`
- `gameplay_level_<n>_candy_asset_url`
- `gameplay_level_<n>_star_asset_url`
- `gameplay_level_<n>_target_asset_url`

资源优先级：

1. 关卡级资源
2. 全局 presentation 资源
3. 默认 Pixi 矢量绘制

不要说“必须依赖本地 png 文件”，当前支持直接使用资源链接。

### 7.3 背景音乐

当前支持：

- `presentation_bgm_asset_url`
- `presentation_bgm_volume`
- `presentation_bgm_loop`
- `gameplay_level_<n>_bgm_asset_url`
- `gameplay_level_<n>_bgm_volume`
- `gameplay_level_<n>_bgm_loop`

行为：

- 有关卡级 BGM 时优先使用关卡级
- 否则回退全局 BGM
- 首次用户交互后解锁播放
- 背景音乐支持循环

当前未读到切绳音效、收星音效、通关音效，不要默认说成已支持。

## 8. HUD 与弹窗规则

### 8.1 HUD

当前 HUD 是顶部左右布局的胶囊化信息面板，包含：

- 关卡
- 分数
- 星星
- Restart

当前 HUD 走 `domui/HudView.js`，不是旧的 Pixi HUD 实现。

### 8.2 Modal

当前 Modal 支持：

- 开始弹窗
- 胜利弹窗
- 失败弹窗
- 文案换行
- scale + fade 动画
- 按钮点击反馈

当前 Modal 同样走 DOM UI 组件。

## 9. 场景与布局规则

### 9.1 布局

当前布局策略：

- 背景资源按 cover 铺满整页
- 游戏世界本身按 contain 放进可视安全区
- 顶部留出 HUD 安全区

因此回答“为什么物体会出页面/被裁切”时，优先检查：

- `src/renderers/cutRope/sceneLayout.js`
- 关卡坐标是否过于靠边
- 物理摆动力是否过大

### 9.2 绳索观感

当前绳索不是纯直线静态渲染，而是：

- 活跃绳索按速度和时间生成轻微弹性曲线
- 已切断绳头会做短时回弹

## 10. 目录职责

### `src/config.json`

- 单一配置源
- 优先在这里改：
  - 关卡参数
  - 绳索锚点与长度
  - 糖果/星星/目标位置
  - 资源链接
  - 背景音乐
  - 文案
  - 颜色
  - 世界参数

### `src/config.js`

- 配置读取层
- 负责平铺 key 聚合
- 负责关卡、资源、音频运行时构建
- 不负责玩法规则

### `src/kernels/cutRopeKernel.js`

- 负责：
  - 开始/重开/继续
  - 切绳状态更新
  - 通关与失败
  - 分数和星星累计
  - 关卡推进
  - 快照生成

### `src/kernels/systems/levelSystem.js`

- 负责关卡运行时构建
- 负责糖果初始出生点稳定化

### `src/kernels/systems/physicsSystem.js`

- 负责：
  - 摆动
  - 重力
  - 阻尼
  - 约束迭代
  - 旋转

### `src/kernels/systems/collisionSystem.js`

- 负责：
  - 星星收集判定
  - 目标命中判定
  - 出界失败判定

### `src/renderers/cutRope/mountCutRopeRenderer.js`

- 负责：
  - Pixi 挂载
  - 背景绘制
  - 资源预加载
  - 背景音乐解锁与同步
  - pointer 输入
  - 订阅 snapshot

### `src/renderers/cutRope/components/SceneView.js`

- 负责：
  - 糖果绘制
  - 绳子绘制
  - 星星绘制
  - 目标绘制
  - 绳子命中检测
  - 绳子弹性与回弹表现

### `src/renderers/cutRope/domui/*.js`

- 负责卡片式 HUD / Modal / 按钮 UI

### `src/renderers/cutRope/systems/*.js`

- `SlashEffectSystem.js`
  - 切割拖尾与火花
- `SceneAssetLibrary.js`
  - 资源加载与缓存
- `BackgroundAudioController.js`
  - 背景音乐播放控制

## 11. 修改优先级

1. `src/config.json`
2. `src/config.js`
3. `src/kernels/cutRopeKernel.js`
4. `src/kernels/systems/levelSystem.js`
5. `src/kernels/systems/physicsSystem.js`
6. `src/kernels/systems/collisionSystem.js`
7. `src/renderers/cutRope/mountCutRopeRenderer.js`
8. `src/renderers/cutRope/components/SceneView.js`
9. `src/renderers/cutRope/domui/*.js`
10. `src/renderers/cutRope/systems/*.js`

判断规则：

- 改文案 / 资源 / BGM / 关卡参数：先改 `src/config.json`
- 配置需要聚合：改 `src/config.js`
- 改规则、胜负、推进：改 kernel
- 改轻量物理：改 `physicsSystem.js`
- 改视觉、交互、媒体、音频触发：改 renderer

## 13. 最小验证清单

每次实质改动后至少验证：

1. 新配置项是否真实被读取
2. kernel 是否没有混入 Pixi / DOM / 音频元素控制
3. renderer 是否没有写玩法判定
4. 运行链是否仍然是 `main -> kernel -> renderer`
5. `ReadLints` 是否无新问题

## 14. 当前未承诺能力

- 气泡、风扇、机关、按钮、钉子等扩展机关

- 静音按钮 / 音量 UI
- 新手引导
- 存档
- 多角色切换
- 复杂道具系统

如果用户需要这些，必须明确为“新增需求”。
