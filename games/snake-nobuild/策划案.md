# snake-nobuild 策划案

## 1. 项目概述

`snake-nobuild` 是一套基于 `CDN + 原生 ESM + Pixi.js` 的 `slither.io` 风格连续路径贪吃蛇模板。当前真实项目已经具备完整单局循环，不是只带骨架的占位 Demo。

当前真实内容包括：

- 连续转向与非网格移动
- 蛇身历史轨迹数组
- 平滑蛇身渲染
- 食物拾取与增长
- 加速按钮与键盘加速
- NPC 生成、游走、追食、重生
- 玩家与 NPC 排行榜
- 死亡掉落食物
- 时间到结束页
- 玩家 / NPC / 食物图片皮肤
- 背景媒体、BGM、吃食物音效、死亡音效
- HUD 与结束页 DOM UI

本项目给模型使用时，必须把它当成**已经可玩、且已经具备配置驱动皮肤与结束页能力的 snake no-build 模板**。

## 2. 模型使用强约束

## 3. 产品定位

### 3.1 目标用户

- 偏好短局、强反馈、低学习成本的移动端休闲用户
- 喜欢 `slither.io` 类吞噬成长体验的用户
- 对换肤、音效、镜头反馈、结束页反馈敏感的用户

### 3.2 产品目标

- 在 3 秒内让用户理解“吃食物变长，避开其它蛇”
- 用短局制和计时结束页控制性能与节奏
- 用音频、皮肤、UI 结束页、排行榜建立商业休闲质感

## 4. 当前核心循环

当前真实单局循环如下：

1. 进入页面，创建世界、玩家蛇、NPC、食物。
2. 玩家通过摇杆 / 鼠标 / 键盘控制蛇头转向。
3. 玩家或 NPC 吃到食物后增长。
4. NPC 在世界内游走、追逐附近食物，必要时追击更短的玩家。
5. 玩家撞边界或撞到存活 NPC 身体时死亡。
6. 玩家死亡后掉落食物并在**同一 round** 内延迟重生。
7. NPC 死亡后掉落食物并按延迟重生。
8. 每局倒计时持续推进。
9. 时间到后本 round 真正结束，展示结束页排行榜、历史最佳与再玩一次按钮。
10. 点击再玩一次，开始新的 round。

## 5. 玩法规则

### 5.1 世界

- 世界大小由 `gameplay_world_width` / `gameplay_world_height` 控制
- 相机跟随玩家
- 允许镜头缩放随长度变化

### 5.2 玩家移动

- 非网格移动
- 基于角速度平滑转向
- 可加速
- 玩家碰世界边界会死亡

### 5.3 增长规则

- 每颗食物基础增长来自 `gameplay_growth_per_food`
- 当前已实现增长软上限：
  - `gameplay_growth_soft_cap_start`
  - `gameplay_growth_soft_cap_range`
  - `gameplay_growth_soft_cap_min_multiplier`
- 蛇越长，后续每颗食物实际增长越温和

不要把当前增长逻辑描述成“固定每颗恒定增长”。

### 5.4 死亡与重生

- 玩家死亡：
  - 掉落食物
  - 触发死亡粒子
  - 同 round 延迟重生
- NPC 死亡：
  - 掉落食物
  - 进入 respawn timer
- 时间到：
  - 结束当前 round
  - 显示结束页
  - 点击按钮开启新 round

### 5.5 排行榜

- 排行榜来源于玩家和 NPC 当前长度
- 常驻 HUD 右侧展示前几名
- 结束页排行榜展示前 5 名
- 玩家本人会被高亮

## 6. 分数与回合

### 6.1 当前“得分”定义

当前左上 HUD 文案显示“得分”，但数值实际展示的是玩家当前长度。回答用户时不要把这两者混为“代码里真的是 score”。

### 6.2 历史最佳

- 历史最佳当前使用本地存储记录
- 结束页展示历史最佳长度

### 6.3 回合规则

- 默认单局时长来自 `gameplay_round_time_limit_seconds`
- 当前默认是短局制
- 只有时间到才结束 round 并生成结束页 summary

## 7. 视觉与媒体规则

### 7.1 背景

当前支持：

- 默认程序绘制背景网格
- `presentation_background_media`
- `presentation_background_media_type`
- `presentation_background_media_fit`
- `presentation_background_media_position`
- `presentation_background_media_opacity`

当前背景已移除额外的两个大圆形光影；不要再把它描述为现有效果。

### 7.2 蛇皮肤

当前支持：

- 玩家蛇头图片
- 玩家蛇身图片
- NPC 默认蛇头 / 蛇身图片
- NPC 皮肤池多套头图 / 身图

资源优先级：

1. 玩家使用玩家图片配置
2. NPC 优先使用皮肤池
3. 若皮肤池未命中，再回退 NPC 默认图
4. 若图片缺失或加载失败，再回退矢量蛇

### 7.3 食物皮肤

当前支持：

- `asset_food_image`
- `asset_food_image_scale`
- `asset_food_rotation_deg`

有图片时显示图片食物；无图时回退默认发光食物粒子。

### 7.4 音频

当前支持：

- 背景音乐
- 吃食物音效
- 死亡音效

行为：

- 首次用户交互后解锁音频
- BGM 循环播放
- 吃食物与死亡通过 effect 序列触发

## 8. HUD 与结束页规则

### 8.1 HUD

当前 HUD 包含：

- 左侧得分卡
  - 当前长度值
  - 剩余时间
- 右侧排行榜

### 8.2 结束页

当前结束页位于 `ui-layer`，包含：

- 顶部“时间到”
- 中间排行榜标题与前 5 名
- 历史最佳
- 再玩一次按钮
- 全屏毛玻璃蒙层

不要把当前结束页描述成“自动关闭”或“死亡也会弹出”。

## 9. 目录职责

### `src/config.json`

- 单一配置源
- 优先在这里改：
  - 回合时间
  - 增长参数
  - 镜头参数
  - 图片 / 音频资源
  - UI 文案
  - 颜色

### `src/config.js`

- 配置读取层
- 负责平铺 key 与路径兼容读取

### `src/kernels/snakeKernel.js`

- 负责：
  - 单局状态
  - tick
  - 食物结算
  - 死亡判定
  - 同局重生
  - 时间到结束
  - round summary

### `src/systems/SnakeSystem.js`

- 负责：
  - 建蛇
  - 移动
  - 增长
  - 长度软衰减
  - 身体裁剪
  - 碰撞辅助

### `src/systems/FoodSystem.js`

- 负责：
  - 初始食物
  - 食物消耗
  - 爆散掉落

### `src/systems/NpcSystem.js`

- 负责：
  - NPC 创建
  - AI 目标选择
  - respawn
  - 皮肤池分配

### `src/renderers/snake/SnakeRenderer.js`

- 负责：
  - Pixi 挂载
  - 背景网格
  - 镜头
  - 音频
  - 皮肤资源加载
  - 食物稳定渲染筛选
  - HUD 与结束页调度

### `src/renderers/snake/domui/*.js`

- `HudView.js`：常驻 HUD
- `EndscreenView.js`：结束页结构
- `theme.js`：DOM UI 样式

## 10. 修改优先级

1. `src/config.json`
2. `src/config.js`
3. `src/kernels/snakeKernel.js`
4. `src/systems/SnakeSystem.js`
5. `src/systems/FoodSystem.js`
6. `src/systems/NpcSystem.js`
7. `src/renderers/snake/SnakeRenderer.js`
8. `src/renderers/snake/domui/*.js`

判断规则：

- 改数值、资源、文案、皮肤、音量：先改 `src/config.json`
- 改 round、重生、时间到、summary：改 kernel
- 改增长曲线、碰撞、身体长度：改 `SnakeSystem.js`
- 改视觉、镜头、结束页、毛玻璃、按钮：改 renderer / domui

## 12. 最小验证清单

每次实质改动后至少验证：

1. 新配置项是否真实被读取
2. kernel 是否没有混入 Pixi / DOM / Audio
3. renderer 是否没有写玩法判定
4. round 逻辑是否仍区分“死亡同局重生”和“时间到结束整局”
5. `ReadLints` 是否无新问题

## 13. 当前未承诺能力

以下内容不要默认说成已支持：

- 游戏内文件上传面板
- 云端存档
- 联机多人
- 道具系统
- 商城 / 换肤商店
- 动态地图事件

如果用户需要这些，必须明确为新增需求。
